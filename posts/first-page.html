第一篇笔记：
用 HTML 和 CSS 写一个页面

从结构到样式，认识一个网页如何组成。

HTMLCSS约 3 分钟阅读

这是一篇用于展示博客排版的示例笔记。你可以直接改写，也可以复制它，开始记录自己的学习过程。

01 / 先准备两个文件

一个简单的网页可以从两个文件开始：index.html 存放内容和结构，styles.css 控制颜色、字号与布局。把它们放在同一个文件夹里，就能开始动手。

02 / 用 HTML 组织内容

标题使用 h1，段落使用 p。下面的例子包含了一个完整网页的基本结构：

<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>我的第一篇笔记</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <main>
    <h1>你好，世界</h1>
    <p>这是我的第一个页面。</p>
  </main>
</body>
</html>

link 元素把样式文件连接到页面；charset 声明文字编码，让中文正常显示。

03 / 用 CSS 留出阅读空间

先处理文字和留白。限制内容宽度、增加行距，可以让长段落更容易阅读。把下面的内容保存到 styles.css：

body {
  margin: 0;
  background: #f8f7f3;
  color: #252a26;
  font-family: system-ui, sans-serif;
  line-height: 1.8;
}

main {
  max-width: 720px;
  margin: 64px auto;
  padding: 0 24px;
}

h1 {
  color: #315a46;
}

04 / 打开、修改、刷新

双击 index.html，浏览器会显示页面。修改文字或样式并保存，再回到浏览器刷新，就能看到变化。

  • 文字乱码：检查文件是否保存为 UTF-8。
  • 样式没生效：检查文件名和 href 中的路径是否一致。
  • 页面没变化：确认保存了文件，并刷新正确的浏览器标签页。

下一次练习：加一条链接，再调整浏览器窗口宽度，看看页面在小屏幕上如何排列。
